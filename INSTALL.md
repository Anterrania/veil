# Install VIPER on iPhone 16

There is no App Store build. This is a standalone PWA.

1. Put public/ + server.py on a host with HTTPS.
2. On the iPhone 16 open Safari (not Chrome) to that URL.
3. Share → Add to Home Screen.
4. Open the VIPER icon.

Flash Player will never load on iOS. The looping marks + flash.js timeline are the replacement.
